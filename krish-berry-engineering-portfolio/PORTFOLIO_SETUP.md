# Krish Berry Engineering Portfolio

## What to edit

- `app/page.tsx` contains all website text and links.
- `app/globals.css` controls colours, layout and responsive styling.
- `app/layout.tsx` contains the browser title and search description.

## Important replacements

1. Replace the `#` LinkedIn and GitHub links near the bottom of `app/page.tsx`.
2. Replace each coloured project placeholder with a real project image or CAD render.
3. Add a public resume PDF only after checking that its contact details are appropriate to publish.

## Run locally

```bash
npm install
npm run dev
```

Open the address displayed in the terminal.

## Publish

This project uses React/Next-style components. It can be deployed through a compatible hosting service. If using a simple GitHub Pages branch deployment, use a static HTML/CSS version or configure a static export workflow first.
